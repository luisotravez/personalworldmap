# Decisions log

Open questions and the decisions already made, so anyone can see why the guide looks the way it does. Propose changes through an issue (see [CONTRIBUTING.md](CONTRIBUTING.md)).

## Decided

| Decision | Reason |
| --- | --- |
| English first, Spanish later | More feedback, global reach and more complete sources. Reach experiments will show which language works better |
| Days 7 and 15 take one hour, the rest 15 to 20 minutes | Producing a video or the first piece of a series needs more time |
| Day 0 is optional and can be nested into day 1 | Lets people learn the process without delaying their first publication |
| Every exercise should help the creator publish from day 1 | Momentum over perfection |
| Public sources only, credited and paraphrased | Respect for creators and for paid material |
| Counterpoints stay in | The guide is one path to explore, not the best one |
| One master version, with forks and public proposals | Keeps a clear reference while allowing adaptation |
| License: CC BY-SA for now | Simple to adapt and share. To be reviewed |
| Day 1 picks at most 3 focus topics for the first two weeks | Focus beats breadth at the start. More topics can appear, but the focus stays at 3 |
| The first filter is called "heck yes" | Adapted from Derek Sivers. A family-friendly name |
| Extra scoring method: Ease, Impact and Energy, 1 to 5 | Adapted from ICE. Energy replaces Confidence because it predicts follow-through |
| Unchosen topics go to a parking lot, not an avoid list | A personal world can keep growing. Topics can come back |
| Skip rule: one skipped day is fine, never skip twice | Supported by habit research. See sources.md, section 12 |
| Tools: the author's picks are Google Drive for notes and Claude for AI; Notion and Obsidian are alternatives | Simple defaults. Others are welcome |
| Day 0 is 20 minutes: read, choose tools, set rules | Keeps the setup short and optional |
